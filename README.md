

​     本系统基于SSM框架开发，采用前后端分离技术，使用Tomcat服务器、MySQL数 据库和 IDEA 工具协助开发。前端采用便捷的微信小程序方式进行开发，并借助 Vant  Weapp UI 组件库来提高界面搭建的效率，通过axios-miniprogram库优化网络请求操作。 

​    本系统主要设计了登录模块、用户信息模块、订阅通知模块、周边产品发布模块、周 边店铺收藏模块、周边产品分类和搜索模块、周边评价模块、周边推荐模块，为用户提 供周边产品信息查询、评价和发布功能。根据用户的收藏行为，向用户推荐相似且未收藏的周边产品。借助信息化的手段实现游戏周边产品信息的整合，为消费者提供一个集中、便捷、详细的商品查询渠道，也为商家提供一个专属的产品展示和发布的平台。
